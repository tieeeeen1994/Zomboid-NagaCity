# Naga City, Philippines

A Project Zomboid Build 42 map of Naga City, Camarines Sur, generated from OpenStreetMap data at one tile per metre:
streets, rivers and buildings in their real places.

- **Where:** added to Knox Country, south-east of Raven Creek. Take Raven Creek's long entry highway to its first gas
  station; the road south-east of the station leads to Naga.
- **What:** the whole urban area.

Build 42 only. Requires Raven Creek B42. Must be installed on the server and on every client.

Work in progress: the map files are not generated yet.
